# Metronome

A small browser metronome built with Vite and vanilla TypeScript, served under `/metronome/`.

## Rules for every change

- Style only with the design tokens; see [Styling](rules/styling.md).
- Design source: [`DESIGN.md`](../../DESIGN.md).

## Commands

- `pnpm dev`, `pnpm build`, `pnpm preview`
- Gate: `pnpm test`, `pnpm lint`, `pnpm typecheck`, `pnpm format:check`, `pnpm build`
